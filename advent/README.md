# Декабрь Илоны — адвент-календарь

Одна страница `index.html`, без сборки и зависимостей (кроме шрифтов Google).

## Как устроено
- 31 окошко, с 1 по 31 декабря 2026. Каждое открывается в свой день (по часам устройства), пропущенные можно открыть позже.
- За каждый пройденный день 1–30 выдаётся буква тайной фразы. Буквы приходят вразнобой, а 31-го нужно сложить из них фразу.
- В финале: салют, фраза и всё, что Илона писала в течение месяца (желание 1-го, плейлист, письмо себе, итоги года).
- Типы дней: загадка, вопрос, задание, купон, морозное стекло (стереть иней), анаграмма, игра «Снегопад», игра на пары, снежный шар с предсказанием, записка.
- После задания дня появляется подсказка, где спрятан настоящий подарок, и кнопка «Нашла!».
- Прогресс хранится в браузере Илоны (localStorage).

План подарков по дням — в `gifts.md`.

## Режим дарителя
Открой ссылку с `#preview` на конце, затем пять быстрых нажатий на заголовок открывают панель: можно открыть все окошки для проверки (прогресс в этом режиме хранится отдельно) и сбросить прогресс.

## Что поменять под себя
Всё в начале `<script>`:
- `CONFIG.phrase` — тайная фраза, ровно 30 букв без пробелов. Сейчас: «ТЫ МОЙ САМЫЙ ГЛАВНЫЙ ПОДАРОК В ЖИЗНИ». `CONFIG.finalHunt` — подсказка про главный подарок после фразы.
- `CONFIG.finale` — финальное поздравление.
- `DAYS` — содержимое каждого дня (тексты, загадки, купоны, задания).

Файл написан для публикации как Claude Artifact (без `<!doctype>`/`<head>`). Для своего хостинга добавь в начало `<!doctype html><meta charset="utf-8"><meta name="viewport" content="width=device-width,initial-scale=1">`.
